# Escanor

> ⚠️ **Этот проект полностью написан ИИ.** Весь код, документация и
> конфигурация созданы с помощью Claude (Anthropic) без ручного написания
> кода человеком. Используйте на свой страх и риск.

Escanor превращает Android-смартфон в веб-камеру, микрофон и макропад для Windows.
Телефон подключается кабелем USB, всё управление — на компьютере.

## Возможности

- **Веб-камера «Escanor Camera»** — её видят Zoom, Discord, OBS, браузеры и приложение
  «Камера». Выбор любой камеры и объектива телефона, до 1080p и 60 к/с.
- **Минимальная задержка:** аппаратное кодирование на телефоне и аппаратное декодирование
  на ПК (Media Foundation + D3D11), 60 к/с по умолчанию, звук через AAudio и WASAPI с
  малым периодом. Задержка и RTT показываются прямо в окне.
- **Микрофон телефона** — в любой виртуальный кабель (VB-Cable, Voicemeeter…), выбор
  микрофона и обработки звука.
- **Настройки камеры с ПК:** масштаб, экспозиция, фокус, баланс белого, стабилизация, фонарик.
- **Макропад** — экран телефона как панель кнопок:
  - сочетания клавиш и кнопок мыши (удерживаются вместе с пальцем — подходит для push-to-talk);
  - переключатели с двумя состояниями и своей картинкой для каждого;
  - запуск программ, файлов и сайтов — exe можно просто перетащить из Проводника;
  - заготовленный текст — печатается в активное окно, с Enter в конце по желанию;
  - саундпад: звуки mp3/wav/ogg/flac в отдельно выбранное устройство вывода, общая громкость и
    выравнивание громкости звуков между собой;
  - папки, перетаскивание кнопок мышью, картинки и их перекраска;
  - иконка программы подставляется сама, её можно взять и вручную;
  - бережный режим для AMOLED: чёрный фон, сдвиг пикселей, затемнение без касаний — время и
    яркость настраиваются.
- **Трей и автозапуск** вместе с Windows, **автообновление** из релизов GitHub.
- **Переносимость:** настройки, картинки и звуки лежат рядом с программой.

## Установка

1. Скачайте `escanor-<версия>-windows-x86_64.zip` из
   [релизов](https://github.com/ExRyuske/Escanor/releases/latest) и распакуйте в любую папку.
2. На телефоне включите «Параметры разработчика → Отладка по USB», подключите кабель и
   разрешите отладку для этого компьютера.
3. Запустите `escanor.exe`. Приложение для телефона установится и запустится само.
4. Нажмите «Установить» в баннере про веб-камеру (один раз, нужны права администратора):
   DLL копируется в `C:\Program Files\Escanor\` — только оттуда её может загрузить
   системная служба камер.
5. Для микрофона установите виртуальный кабель (например, VB-Cable) и выберите в Escanor
   «Передавать в: CABLE Input», а в Zoom/Discord — микрофон «CABLE Output».

Требования: Windows 11, Android 11+ (проверялось на Pixel 5).

### Обновление и перенос

Escanor сам проверяет новые версии (вкладка «Настройки»), скачивает пакет, сверяет
SHA-256, заменяет файлы и перезапускается; телефон обновляется при подключении.
Настройки (`settings.json`), картинки и звуки макропада (`macropad/`) хранятся рядом с программой —
папку можно просто скопировать на другой компьютер. При ручном обновлении копируйте новые
файлы поверх, не удаляя эти два пункта.

## Сборка

```sh
make run       # программа на этом компьютере (на macOS — превью и звук, без веб-камеры)
make apk       # собрать и поставить приложение на подключённый телефон
make package   # пакет для Windows: dist/release/escanor-<версия>-windows-x86_64.zip (+ .sha256)
make check     # форматирование, clippy и тесты — как в CI
```

Нужны Rust (stable), для Android — JDK 17+, Android SDK 35, NDK 28 и CMake 3.22 (путь к SDK —
в `android/local.properties`). `make package` на macOS собирает через
[`cargo-xwin`](https://github.com/rust-cross/cargo-xwin), на Windows — напрямую.

APK подписывается общим ключом `android/escanor.keystore`: иначе Android не ставил бы
обновление поверх версии, собранной на другой машине. Приложение ставится только через
adb с компьютера пользователя, поэтому ключ хранится в репозитории.

## Выпуск

`.github/workflows/ci.yml` устроен как в YeruHost: предложения (pull request) проходят
проверки, а push в основную ветку выпускает версию — поднимает её (`scripts/release.py`),
собирает APK и пакет для Windows, ставит тег и публикует релиз, который затем находит
встроенное обновление. `minor`/`major` — Actions → CI → Run workflow; пропустить выпуск —
`[skip ci]` в сообщении коммита. Зависимости обновляет dependabot раз в месяц.

## Структура проекта

```
android/          приложение для телефона (Kotlin; захват звука — C/AAudio)
desktop/app       программа для ПК: интерфейс (iced), трей, настройки, обновления
desktop/core      связь с телефоном, декодирование, звук, макропад, веб-камера
desktop/vcam      DLL виртуальной камеры Windows 11 (Media Foundation)
desktop/shm       общая память между программой и DLL камеры
docs/protocol.md  протокол телефон ↔ ПК
scripts/          сборка пакета, выпуск версии
```
